EMBEDDED / OPEN SOURCE

Netmate

让路由器的状态，一眼可见。

一台基于 STM32F411 的 OpenWrt 路由器状态监控仪表盘。通过 ESP-01S 连接路由器，把网络与系统信息呈现在桌面上的 2.8 英寸触控屏里。

STM32F411ESP-01SLVGLFreeRTOSCMakeC

01

网络信息，直观呈现

查看 Wi-Fi 信号强度、信道和频段，了解当前无线网络状态。

02

路由器运行状态

展示 CPU 负载、内存使用率与在线设备数，把关键指标集中到一块屏幕上。

03

触控交互与实时任务

使用触控切换信息页面，结合 LVGL 图形界面与 FreeRTOS 任务调度。
